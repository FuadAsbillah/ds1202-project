# DS1202 AS02 - Server Access & Git Proficiency

## Overview
This repository contains an automated system information shell script (`sysinfo.sh`) created for the **DS1202 ICT Infrastructure Basics** module at Politeknik Brunei. The script collects key server diagnostic metrics and logs output for system auditing.

## Setup & Directory Structure
The project structure on the Linux server is organized as follows:
- `scripts/`: Contains `sysinfo.sh` (executable system reporting script)
- `logs/`: Stores output generated by `sysinfo.sh` (`sysinfo.log`)
- `docs/`: Reserved for project documentation

Directory permissions are configured to `755`:
```bash
mkdir -p ~/ds1202-project/{scripts,docs,logs}
chmod 755 ~/ds1202-project
